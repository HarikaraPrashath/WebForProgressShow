# Web For Progress Show

A modern Research Dashboard and Academic Milestones tracker built with Next.js, Framer Motion, and Tailwind CSS.

## 🚀 Live Deployment
The project is live at: **[https://web-for-progress-show.vercel.app/](https://web-for-progress-show.vercel.app/)**

## ✨ Features
- **Dynamic Research Dashboard**: Highlighting key research components.
- **Academic Milestones**: Track progress, assessments, and marks.
- **Modern UI**: Built with a premium aesthetic using Tailwind CSS and Lucide icons.
- **Smooth Animations**: Interactive experience powered by Framer Motion.

## 🛠️ Tech Stack
- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React

## 📦 Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
