# Web For Progress Show

A modern Research Dashboard and Academic Milestones tracker built with Next.js, Framer Motion, and Tailwind CSS.

## 🚀 Live Deployment
The project is live at: **[https://web-for-progress-show.vercel.app/](https://web-for-progress-show.vercel.app/)**

## ✨ Features
- **Dynamic Research Dashboard**: Highlighting key research components.
- **Academic Milestones**: Track progress, assessments, and marks.
- **Modern UI**: Built with a premium aesthetic using Tailwind CSS and Lucide icons.
- **Smooth Animations**: Interactive experience powered by Framer Motion.

## 🛠️ Tech Stack
- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React

## ⚙️ Local Setup Guide

Follow these steps to get the project running on your local machine:

### 1. Prerequisites
Ensure you have **Node.js** (v18 or higher) installed.

### 2. Clone the Repository
```bash
git clone https://github.com/HarikaraPrashath/WebForProgressShow.git
cd WebForProgressShow
```

### 3. Install Dependencies
```bash
npm install
# or
yarn install
```

### 4. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

### 5. Build for Production
To create an optimized production build:
```bash
npm run build
npm run start
```
